# Contributing

1. Fork this repo and clone your fork.
2. Follow the install steps in the README to get the tracker running.
3. Play the game. The tracker will fill in `locations.csv`/`items.csv` as you go.
4. Commit your changes and open a pull request against this repo's `main` branch.
5. All PRs require review before merging, mainly to check for duplicate or inconsistent rows.
